# District City Launcher

Desktop launcher for District City Roleplay. Install it from the latest release: [DistrictCityRP-Setup.exe](https://github.com/JanzenDC/DistrictCity-Launcher/releases/latest).

Sign in with the username and password you use in the city. **Play** opens Multi Theft Auto and connects to the server.

- Map, handbook, players online, and ranking
- Launcher chat, separate from the chat in the city
- Your character, faction or gang, money, vehicles, and property
- **Update** replaces **Play** when a newer build is published
